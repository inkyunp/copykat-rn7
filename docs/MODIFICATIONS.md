# CopyKAT rat (rn7) fork — modifications vs original

Based on upstream **copykat 1.1.0**, commit `b795ff793522499f814f6ae282aad1aab790902f`
(navinlabcode/copykat). The original function sources were restored byte-faithfully via
`srcref` from the package installed in the existing Rocky9 CNV SIF
(`docs/original_copykat_b795ff7.R`). The full unified patch is
[`copykat_rn7.patch`](copykat_rn7.patch).

## Summary: 3 code edits + 1 data object

| # | Location | Change | Purpose |
| --- | --- | --- | --- |
| 1 | `copykat()` step 2 annotation branch | add `else if(genome=="rn7")` | make rat values match a branch (originally there is no `else`, so unsupported values die immediately) |
| 2 | `copykat()` later gene-space block | `if(genome=="mm10")` → `if(genome=="mm10" || genome=="rn7")` | let rat inherit the mouse gene-space downstream (no 220kb bin) verbatim |

| 4 | `R/sysdata.rda` | add `full.anno.rn7` | bake the mRatBN7.2 rat annotation table (existing `full.anno`/`full.anno.mm10`/`DNA.hg20`/`cyclegenes` kept as-is) |

Metadata: `DESCRIPTION` Version `1.1.0` → `1.1.0.9001`, and one line
`export(annotateGenes.rn7)` added to `NAMESPACE`.

## What was **not** changed (deliberately)

- **The hg20-only steps are untouched.** Cell-cycle/HLA gene removal (`if(genome=="hg20")`)
  and the 220kb genomic-bin conversion (`convert.all.bins.hg20`) are already gated to
  `genome=="hg20"`, so rn7 automatically skips these steps.
- **The `mgi_symbol` column name is kept verbatim.** The copykat body references this name
  directly (e.g. `rownames(mat.adj) <- anno.mat2$mgi_symbol`), so it holds rat symbols but
  renaming the column would break the code. `full.anno.rn7` therefore keeps its 6th column
  literally named `mgi_symbol` and stores rat gene symbols in it.
- **The algorithm logic (filtering, smoothing, baseline, MCMC segmentation) is the original.**

## Detailed diff

### Edit 1 — annotation branch (near original line 40)
```diff
   } else if(genome=="mm10"){
   anno.mat <- annotateGenes.mm10(mat = rawmat, ID.type = id.type) #SYMBOL or ENSEMBLE
   dim(rawmat)
+  } else if(genome=="rn7"){
+  anno.mat <- annotateGenes.rn7(mat = rawmat, ID.type = id.type) #SYMBOL or ENSEMBLE (rat mRatBN7.2)
+  dim(rawmat)
   }
```
The original has only `hg20`/`mm10` branches and no `else`, so simply passing
`genome="rn7"` leaves `anno.mat` uncreated and the next line
(`anno.mat[order(...)]`) dies with an "object not found" error.

### Edit 2 — gene-space output block (near original line 558)
```diff
-  if(genome=="mm10") {
+  if(genome=="mm10" || genome=="rn7") {
     uber.mat.adj <- data.matrix(results.com)
```
This block handles the mouse-style (gene-space) final prediction, `CNA_results.txt`, and
heatmap. The hg20-only 220kb bin path (`if(genome=="hg20") convert.all.bins.hg20(...)`) is
already branched above, so rn7 just runs this block and finishes in gene-space.

### Edit 3 — new `annotateGenes.rn7()` (appended to the file)
Body is identical to `annotateGenes.mm10()`; only the default argument differs:
```diff
-annotateGenes.mm10 <-
-function(mat, ID.type="S", full.anno=full.anno.mm10){
+annotateGenes.rn7 <-
+function(mat, ID.type="S", full.anno=full.anno.rn7){
```
`id.type="S"` intersects the count matrix with `full.anno$mgi_symbol`, `"E"` with
`full.anno$ensembl_gene_id`, then dedupes `mgi_symbol` and binds annotation + expression.
Because the `mgi_symbol` column name is preserved, the function body needs no other change.

### Data 4 — `full.anno.rn7` (R/sysdata.rda)
Generated by `build_full_anno_rn7.R` from `genes.gtf` (mRatBN7.2, GCA_015227675.2)
`feature=="gene"` rows. Same 7-column schema as `full.anno.mm10`:

| Column | Content |
| --- | --- |
| `abspos` | real cumulative coordinate (per-chromosome max-end offset + start). Does not reproduce the constant-abspos defect of the bundled `full.anno.mm10` (20 unique / 137,030) — rn7 has 25,268 unique / 25,302 |
| `chromosome_name` | integer encoding (autosomes 1–20, X=21; Y/MT/scaffolds excluded) |
| `start_position`, `end_position` | gene coordinates |
| `ensembl_gene_id` | Ensembl gene ID (`id.type="E"` matching) |
| `mgi_symbol` | **rat** gene symbol (column name kept) |
| `band` | `NA` (visualization only, unused by math) |
